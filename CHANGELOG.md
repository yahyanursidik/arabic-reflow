# Changelog

## 0.8.0 — 2026-10-11

- Source-preserving Arabic reading: full-width images without a viewport-height cap,
  a 200% inspection view with RTL scrolling, an intact fit-width view, and return links.
- Clearer book typography, explicit footnote labels and verified reference/back links,
  inline source word images, and embedded Arabic fonts under the SIL OFL license.
- Responsive PDF, review, preview and export panels with larger touch controls,
  text sizing, page navigation, image inspection and clearer download settings.
- Reversible text repair, image fallback, source comparison, quality reporting and
  export validation; edited blocks are protected from automatic replacement.
- Supplied Arabic Reflow artwork across app branding, browser/home-screen icons,
  share metadata and repository documentation. Book content has no app branding added.
- Version 0.8.0 aligned across engine, API and web app; CI covers engine, web and workflow.
